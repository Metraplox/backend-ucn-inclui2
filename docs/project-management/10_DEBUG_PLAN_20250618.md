## Detalle de Acciones

### Fase 0 – Salvaguarda
1. `git checkout -b debug/limpieza-dart-2025-06-18`
2. `git add . && git commit -m "Snapshot antes de limpieza de linter"`

### Fase 1 – Fix & Format
```
cd front/backend-ucn-inclui2/incluye_app
flutter pub get
dart fix --apply
dart format .
```

### Fase 2 – Errores de compilación
- Imports rotos (`uri_does_not_exist`)
- Métodos faltantes (`undefined_method`)
- Parámetros requeridos (`missing_required_argument`)
- Clases no creadas (ej.: `TasksScreen`, `ReportsScreen`)

### Fase 3 – Warnings críticos
- `avoid_print` → migrar a `logger`
- `use_build_context_synchronously` → `if (!mounted) return;`
- Renombrar archivos `file_names` y variables `non_constant_identifier_names`

### Fase 4 – Mejores prácticas
- Pre-commit con `dart format` + `flutter analyze`
- `analysis_options.yaml` actualizado

### Fase 5 – CI & Tests
- Ejecutar `flutter test` mínimo en servicios y widgets clave.
